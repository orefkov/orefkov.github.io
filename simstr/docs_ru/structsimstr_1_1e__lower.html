Генерирует строку на основе исходной, заменяя все прописные буквы первой плоскости Юникода на строчные.

Параметры шаблона
K- тип символов, выводится на основе исходной строки.

Берёт исходную строку и копирует её, заменяя прописные буквы первой плоскости Юникода на строчные. В качестве исходной строки может браться любой строковый объект.

Generate a string from the original one, replacing all uppercase letters of the first Unicode plane with lowercase ones.

Параметры шаблона
K- character type, inferred based on the source string.

Takes the original string and copies it, replacing the uppercase letters of the first Unicode plane with lowercase ones. Any string object can be taken as the source string. Пример

stringa lower = "Lower case version is: '" + e_lower(source_str) + "'.";
